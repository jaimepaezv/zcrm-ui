# ZCRM - Responsive Bootstrap 5 Admin Dashboard

ZCRM is a modern, responsive admin interface built with Bootstrap 5.3, designed to streamline management for CRMs, CMSs, and a wide range of web applications. Its intuitive, user-centric layout and advanced customization options enable efficient data handling and workflow optimization, ensuring a seamless and scalable enterprise experience.

## Features

- **Fully Responsive Design:** Optimized for all devices with fluid grids and flexible layouts.
- **Modular Components:** Reusable UI components for rapid development.
- **Multi-purpose Functionality:** Suitable for CRMs, CMSs, project management tools, and other web applications.
- **Dark/Light Mode:** Toggle between dark and light themes with ease.
- **Customizable Layouts:** Multiple sidebar, header, and content configurations.
- **Pre-built Pages:** Includes dashboard, user profiles, chat, calendar, file manager, and more.
- **Charts & Data Visualization:** Integrated with ApexCharts for dynamic data representation.
- **Authentication Pages:** Ready-to-use login, registration, and error pages.

## Technologies Used

- **HTML5**
- **CSS3**
- **JavaScript (ES6)**
- **Bootstrap 5.3**
- **External Libraries:**
  - [ApexCharts](https://apexcharts.com/)
  - [Remix Icon](https://remixicon.com/)
  - [SimpleBar](https://grsmto.github.io/simplebar/)

## Getting Started

### Prerequisites

Ensure you have a modern web browser installed (Chrome, Firefox, Safari, Edge).

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yourusername/zcrm-dashboard.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd zcrm-dashboard
   ```

3. **Open `index.html` in your browser:**
   - Double-click the `index.html` file or serve it using a local server like `Live Server` in VSCode.

## Customization

- **Theme Configuration:** Modify `assets/js/config.js` to adjust global settings.
- **Adding New Pages:** Duplicate existing HTML files and customize content.
- **Updating Styles:** Edit `assets/css/app.min.css` for custom styling.
